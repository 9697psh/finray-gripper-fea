# 네덜란드 온실채소 표준작업시간(Taaktijden) 요약

**원문:** Ing. A.T.M. Hendrix, *Taaktijden voor de groenteteelt onder glas II* (온실 채소 재배 표준작업시간 II), 네덜란드 기계화·노동·건축연구소(IMAG), 바헤닝언, 1980년대(본문 예시가 1982년 7월 단체협약 임금을 쓰고 있어 1983년 무렵 발행으로 추정), 73쪽.
- 이전판 IMAG 간행물 147호의 후속(5번째 증보판)입니다.
- 스캔본이라 OCR로 읽은 수치 일부에 오독이 있을 수 있습니다.

**자료 성격**
- 스톱워치로 측정한 시간 연구(time study)를 바탕으로, 작업 방법·도구·조건별 **표준작업시간**을 정리한 실무용 표준 책자입니다.
- 표준작업시간은 정상 속도와 숙련도로 일할 때 그 작업에 써도 되는 시간입니다. 필요한 휴식, 개인 용무, 부수 작업, 방해 요소가 모두 포함돼 있습니다.
- 대상은 상추, 토마토, 오이, 파프리카와 소규모 작물(엔다이브, 배추, 콜라비, 무, 양상추, 펜넬)입니다. 피클오이와 온실 딸기는 실측 표준이 아니라 농가 노동 장부에서 나온 경험치입니다.
- **주의:** 40년 넘은 자료입니다. 당시 토마토는 낱개로 따는 원형 토마토(kg당 13~20개)가 기준이고, 재배 방식(토경 위주, 초기 하이와이어)과 품종이 지금과 다릅니다. 절대값보다는 **도구·조건별 상대 비교와 기준선**으로 쓰는 것이 맞습니다.

## 1. 표준작업시간의 활용 방식 (책자 2장)

현장에서 노동을 어떻게 계획하고 관리했는지 보여주는 부분이라, AS-IS 프로세스의 역사적 기준이 됩니다.

1. **연간 계획:** 작업 종류 × 수량 × 표준시간으로 월별 필요 노동시간을 계산하고, 상시 인력이 낼 수 있는 시간과 비교해 임시 인력 필요량을 판단합니다.
   - 예: 토마토 2만 주, 상시 인력 2명인 농장의 5월 필요 노동은 973~1,002시간인데, 가용 시간은 418시간입니다.
   - 5월 필요 노동 중 수확·선별·경매 출하가 611시간(약 61%)을 차지합니다.
   - 같은 예에서 수확 표준은 50분/100kg이고, 5만 kg 수확에 417시간이 듭니다.
2. **주간·일일 계획:** 연간 계획을 작업자·조별 할당량으로 쪼갭니다.
3. **노동 장부:** 작업 수첩이나 작업 전표에 작업·수량·시간을 매일 적고, 주말에 집계표로 합산합니다. 이것이 이후 통로 등록 시스템의 전신입니다.
4. **작업 평가:** 성과율 = 표준시간 ÷ 실제 시간 × 100. 예를 들어 수확 실적이 51분/100kg이면 50 ÷ 51 = 98%입니다.
5. **성과급:** 표준시간을 기준으로 작업량을 정하고 할증을 줍니다. 예: 잎 따기 표준 15시간짜리 일을 12시간에 끝내면 성과율 125%이고, 그만큼 할증이 붙습니다.
6. **작업 방법·장비 비교:** 새 기계나 운반 수단을 살지 판단하는 근거로 씁니다.

## 2. 토마토 수확 표준시간 (분/100kg)

수확 1회당 수확량(kg/㎡)과 과실 크기(kg당 개수)에 따라 시간이 달라집니다. 아래 범위는 수확량 0.5 kg/㎡ 기준이고, kg당 13~20개 범위입니다.

| 수확 방식 | 분/100kg | 시간당 환산(필자 계산) |
|---|---|---|
| 손바구니 | 50~66 | 91~120 kg/h |
| 4륜 수확 대차 + 상자 (6단 트러스 아래) | 31~44 | 136~194 kg/h |
| 파이프레일 대차, 앉아서 (1~2.5단) | 31~45 | 133~194 kg/h |
| 파이프레일 대차, 걸으며 (2.5단 위) | 27~36 | 167~222 kg/h |
| 전동 파이프레일 대차 (6단 위) | 33~42 | 143~182 kg/h |
| 모노레일 + 바구니 | 36~49 | 122~167 kg/h |

- **수확량 밀도의 영향:** 0.1 kg/㎡로 수확량이 적으면 49~98분/100kg으로 크게 느려집니다. kg당 탐색·이동 시간이 늘기 때문입니다.
- **도구 효과(필자 계산):** kg당 15개, 0.5 kg/㎡ 조건에서 바구니는 53분, 파이프레일(보행)은 29분입니다. 수확 보조 도구만 바꿔도 시간이 약 45% 줄어듭니다.
- **과실 1개당 속도(필자 계산):** 1,500개(100kg)에 29분이면 개당 약 1.2초입니다. 휴식 여유가 포함된 값입니다. 로봇의 과실당 사이클 시간 목표와 비교할 기준선으로 쓸 수 있습니다.

## 3. 수확물 운반·취급 표준시간 (토마토, 분/100kg)

| 작업 | 표준시간 |
|---|---|
| 저장 대차 운반: 600 kg 대차 / 300 kg 대차 | 0.6 / 1.2 |
| 선별기 앞 저장 대차 교체: 600 kg / 300 kg | 0.4 / 0.8 |
| 빈 상자를 온실로 운반·배분 (전동차, 54상자) | 1.6 |
| 온실에서 꽉 찬 상자 수거해 창고로 (전동차, 54상자) | 2.3 |
| 꽉 찬 상자(20 kg)를 선별기 투입부에 넣기 | 1.0 |
| 크기 선별기 선별 (계량, 상자 적재 포함) | 11.4~29 (불량·이색과 비율에 따라) |
| 상자를 트럭에 싣기: 손으로 / 팔레트·지게차로 | 13 / 1.1 (분/100상자) |

- 대차 용량을 300 kg에서 600 kg으로 늘리면 운반·교체 시간이 절반이 됩니다.
- 운반·상자 취급만 더해도 약 6분/100kg입니다. 수확 시간(약 30~50분/100kg)의 12~20% 수준입니다(필자 계산).

## 6. 우리 프로젝트에 주는 시사점

| 원문 내용 | 로봇 A/B 설계 시사점 |
|---|---|
| 사람의 토마토 수확 속도는 과실당 약 1.2~2.6초(휴식 여유 포함) | 수확 팔 사이클 목표의 하한 기준. 국내 로봇은 개당 약 15초라, 수확 팔보다 판단·운반·기록을 먼저 하는 단계적 전략을 뒷받침합니다. |
| 수확 보조 도구(파이프레일 대차)만으로 수확 시간 약 45% 감소 | 로봇 B가 대차 역할(동행·적재)만 해도 큰 효과를 기대할 수 있다는 근거. 작업자가 상자를 들고 오가는 시간을 없애는 것이 핵심입니다. |
| 대차 용량을 2배로 늘리면 운반·교체 시간이 절반 | 로봇 B의 적재 용량(300 kg급)과 집하장 자동 왕복(셔틀)의 효과를 설명하는 근거. |
| 운반·상자 취급이 수확 시간의 약 12~20% | 로봇 B 운반 자동화로 절감할 수 있는 범위. 2010년 WUR 논문의 약 9%(대차 운반 전담 노동)와 함께 범위로 제시할 수 있습니다. |
| 수확량 밀도(kg/㎡)가 낮으면 kg당 시간이 급증 | 로봇도 똑같이 탐색·이동 비중이 커집니다. 로봇 A가 수확 대상 위치를 미리 맵에 표시해 B와 작업자를 그곳으로 보내면 비수확 이동을 줄일 수 있습니다. |
| 작업·수량·시간을 매일 장부에 적고 표준시간 대비 성과율로 평가·성과급 지급 | 로봇 B가 작업자, 통로, 상자, kg을 자동 기록하면 성과율 계산과 성과급 산정까지 자동화할 수 있습니다. 기록 정확도가 임금과 직결된다는 점에서 B-L 요구사항의 근거가 됩니다. |
| 성수기(5월) 필요 노동이 가용 인력의 2배 이상 | 로봇이 성수기 임시 인력 수요를 줄이는 효과로 설명할 수 있습니다. |
| 선별 시간이 불량·이색과 비율에 따라 11.4분에서 29분까지 2.5배 차이 | 로봇 A의 숙도 판단이 정확해 미숙·불량과 혼입이 줄면 선별 노동도 줄어듭니다(간접 효과). |
